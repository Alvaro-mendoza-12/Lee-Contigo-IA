# Licencias de audio

Sonidos y música de LeeContigo IA. Cada archivo nuevo de audio debe tener una fila aquí antes de
subirse al repositorio.

| Archivo | Autor | Fuente | Licencia |
| --- | --- | --- | --- |
| Efectos `pagina`, `correcta`, `incorrecta`, `pista`, `nivel`, `boton` (`lib/sonidos.ts`) | Equipo LeeContigo | Generados por código con Web Audio API | Propia del proyecto (sin archivos de terceros) |
| Caja musical de respaldo (`lib/sonidos.ts`) | Equipo LeeContigo | Generada por código con Web Audio API | Propia del proyecto (sin archivos de terceros) |
| `public/sonidos/musica.ogg` y `musica.mp3` | — | **Pendiente:** todavía no existen | — |

Mientras no existan los archivos de música, `lib/sonidos.ts` usa la caja musical generada. Al
agregar música, usa solo pistas CC0 o con una licencia que permita su uso sin costo y completa la
fila con el autor, el enlace exacto de la fuente y la licencia.
